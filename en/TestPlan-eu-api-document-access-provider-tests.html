TestPlan: Document Access Provider Test Plan (Experimental)

Official URL: http://example.com/fhir/hl7.fhir.eu.health-data-api.test/TestPlan/eu-api-document-access-provider-tests Version: 0.1.0
Draft as of 2026-11-06 Computable Name: DocumentAccessProviderTestPlan

Test plan for the Document Access Provider actor of EU Health Data API, 1.0.0-ballot. The SUT serves EEHRxF documents to Document Consumers, behind SMART Backend Services. Each suite below is a Rule: of the Gherkin feature named by suite.input.file, and each suite.test one of its Scenario: lines, matched by the scenario's identifier. The assertions are the scenario's Then steps, verbatim. The tests declare which specification obligations they cover (24 requirement paths named by the feature tags). Fixture prerequisites, input bindings and expected data are in tests/fixtures/provider-v1/manifest.json, keyed by scenario ID. See the Testing page, Fixture contract and expected results. Provider fixtures are R4; client workflows use the canned data embedded in their feature.
